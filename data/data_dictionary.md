# Data Dictionary

## Dataset Overview

This synthetic dataset simulates customer interactions with subscription-based digital products.

The dataset is designed to support:

* Product Adoption Analysis
* Funnel Analysis
* Customer Segmentation
* Geographic Demand Analysis
* Market Expansion Analytics

## Columns

| Column             | Description                                       |
| ------------------ | ------------------------------------------------- |
| user_id            | Unique customer identifier                        |
| visit_date         | Date of interaction                               |
| city               | Customer city                                     |
| state              | Customer state                                    |
| city_tier          | Tier 1 / Tier 2 / Tier 3                          |
| age_group          | Customer age segment                              |
| income_bracket     | Low / Medium / High                               |
| occupation         | Customer occupation category                      |
| traffic_source     | Acquisition channel                               |
| product_name       | Product viewed                                    |
| homepage_visit     | Homepage visit indicator                          |
| product_page_visit | Product page visit indicator                      |
| purchase_flag      | Purchase indicator                                |
| plan_type          | Monthly / Quarterly / Annual                      |
| purchase_amount    | Revenue generated                                 |
| service_available  | Whether service is available in customer location |
